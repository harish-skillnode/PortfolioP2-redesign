# **App Name**: Sri's Folio

## Core Features:

- Glass Header: Fixed, semi-transparent header with glass style (frosted glass look) that stays visible on scroll. The header provides navigation links to different sections of the page and includes a subtle transition effect on scroll to enhance the user experience.
- Hero Section: Hero section with large, bold text displaying "Sriharish Eswarathas" and "Software Engineer." It also features a typing animation with the phrase "I build experiences that are fast, functional, and visually engaging."
- About Section: Displays Sriharish's background, skills, and values as a developer.
- Project Showcase: Displays recent projects and job experiences in a grid or list format.  Each item includes the project name or role, a brief description, the technologies used, and a link to GitHub or a live demo.
- Contact Section: Basic contact form to facilitate communication (Name, Email, Message).
- Social Links: Displays icons linking to GitHub and LinkedIn profiles.

## Style Guidelines:

- Primary color: Deep Indigo (#483D8B) for a modern, tech-focused feel. This color will be used sparingly for important UI elements to draw attention without overwhelming the user.
- Background color: Near-black (#121214) to provide a dark theme inspired by carbon fiber aesthetics, focusing on readability and modern appeal.  
- Accent color: Electric Violet (#8F00FF) as a vivid highlight for interactive elements. Its higher brightness and saturation add flair and improves UX.
- Headline font: 'Poppins' (sans-serif) for a clean, contemporary feel. It's used for headings and key information.
- Body font: 'Inter' (sans-serif) for readability and a neutral tone in longer texts, which balances effectively with 'Poppins'.
- Outlined icons with a glowing effect to match the futuristic carbon fiber aesthetic.
- One-page scroll layout for easy navigation. Sections flow smoothly for an intuitive user experience.
- Subtle scrolling animations for smooth transitions between sections.
